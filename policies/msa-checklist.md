# Acme MSA checklist (fictional)

Every research pack must assess each item below in its **Policy check** table,
using only public information. Mark each item `met`, `gap`, or `unknown`.
Any `gap` or `unknown` is a policy gap: Legal is added as a reviewer.

| ID | Item | What "met" looks like |
| --- | --- | --- |
| dpa | Data processing agreement | A DPA is published or offered on the vendor's public site |
| certification | Security certification | Public claim of SOC 2 Type II or ISO 27001 |
| subprocessors | Sub-processor list | A public, current list of sub-processors |
| deletion | Data deletion on exit | Public commitment to delete customer data after termination |
| breach-notice | Breach notification | Public commitment to notify within 72 hours |
| residency | Data residency | Public statement of where customer data is stored |
| liability | Liability cap | Liability terms published in public terms of service |
