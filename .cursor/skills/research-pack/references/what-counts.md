# What counts as a good finding

Good: one fact, one source.

- Holds a SOC 2 Type II report, available under NDA ([trust page](https://brightline-analytics.example/trust))

Not good:

- "Seems secure" (opinion, no source)
- "Probably stores data in the US" (guess: make it an open question instead)
- A link to a login page or a private document (not public)

Policy check statuses:

- `met`: the public page says it clearly; cite it.
- `gap`: the public page says something that falls short (e.g. breach notice within 7 days, not 72 hours).
- `unknown`: no public information. Add an open question.
